0.27.0 (03/08/2026)

This release contains the following enhancements and fixes:

  • Reimplemented commit message parsing, improving syntax handling and support for incomplete messages, bodies, footers, multiline footer values, and recent VCS commit tokens (closes #124 and #128).
  • Fixed an OOM issue when parsing a commit type that starts with ! (closes #161).
  • Improved template completion: move freely between segments without losing entered values and clean up empty footer fields when finishing a template.
  • Restored spellchecking for commit messages, which had stopped working after the migration to the Grazie-based platform implementation.
  • Added a confirmation before clearing the local commit message history (closes #147).
  • Moved Conventional Commit settings under Tools.
  • Used the IDE locale by default, while allowing an override through the com.github.lppedd.cc.locale registry option (closes #126).
  • Added the Fixes and Assisted-by built-in footer types (closes #164).
  • Improved custom token file handling: exported files now include the appropriate versioned schema reference.
  • Used the IDE file chooser consistently when selecting token-related files.
  • Loaded tokens in the plugin's Settings page on the appropriate background thread (closes #162).
  • Prevented errors when accessing VCS log providers (closes #150).
  • Expanded compatibility verification to IDEA 2026.1 and 2026.2.
  • And a lot of other stuff that I'm too lazy to list.
